# [应用名称] 前端模板

校园生活应用的脱敏前端源码，使用 **uni-app + Vue 3 + TypeScript + Pinia**。保留首页、服务详情、日程、图书馆选座、图表和六种时段主题，适合学习和二次开发。

**这是离线演示版。所有账号标签、金额、房间、课程、交易和座位均为虚构。无需输入账号或密码。预约、绑定等按钮只模拟本地交互，不产生实际业务操作。**

## 本地运行

建议使用 Node.js 20 或更高版本及 npm。

```sh
npm ci
npm run dev:h5
```

开发服务使用本机端口 `5178`。生产构建：

```sh
npm run audit:public
npm run typecheck
npm run build:h5
```

H5 产物位于 `dist/build/h5`，可以交给静态 HTTP 服务预览。演示版的内容安全策略禁止业务网络连接，因此开发模式的自动热刷新连接也会被阻止；修改后可手动刷新。

## 目录

```text
src/pages/          首页、日程、图书馆
src/components/     通用组件、图表与详情面板
src/composables/    时段主题
src/data/demo.ts    手工编写的虚构演示数据
src/stores/         本地内存状态与模拟操作
src/static/         图标、插画及应用资源
src/styles/         H5 适配样式
scripts/           公开源码检查
```

主题选择会保存在本机；演示资料与模拟记录只保存在内存中，刷新后重置。可以在 `src/data/demo.ts` 中修改演示内容。
